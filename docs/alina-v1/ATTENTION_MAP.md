# ALINA v1 — Attention Map

## Research

- **Primary:** Knowledge Graph / active document analysis
- Secondary: sources, hypotheses, entity/context inspector
- Background: indexing, RAG, OSINT collection
- Alerts: contradiction, source integrity, task failure
- Agent activity: compact feed
- Avatar: bust or compact consultant
- Reason tag: `scenario:research`

## Coding

- **Primary:** editor / implementation surface
- Secondary: terminal, tests, architecture/context
- Background: build, indexing, agents
- Alerts: build/test/security failure
- Agent activity: development feed
- Avatar: compact or voice-only
- Reason tag: `scenario:coding`

## Security

- **Primary:** attack/security graph or active incident
- Secondary: alerts, assets, timeline, controls
- Background: scans, enrichment, correlation
- Alerts: critical security conditions may interrupt
- Agent activity: SOC/security specialist feed
- Avatar: compact/right-side analyst
- Reason tag: `scenario:security`

## Presentation

- **Primary:** one large visualization/story surface
- Secondary: presenter notes and minimal controls
- Background: hidden/collapsed
- Alerts: only critical
- Agent activity: hidden unless requested
- Avatar: full or hologram
- Reason tag: `scenario:presentation`

## Focus

- **Primary:** one document/editor/task surface
- Secondary: collapsed
- Background: silent
- Alerts: critical only
- Agent activity: hidden
- Avatar: hidden or voice-only
- Reason tag: `scenario:focus`
