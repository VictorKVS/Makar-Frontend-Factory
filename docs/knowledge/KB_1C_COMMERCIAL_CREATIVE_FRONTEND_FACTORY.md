# KB-1C — Makar Commercial Creative Frontend Factory

## Mission

Makar must be able not only to build beautiful interfaces, but to turn that capability into a **repeatable commercial delivery system**.

The commercial unit is not "a pretty page". It is a traceable product package:

```text
Lead
  ↓
Brief
  ↓
Scope + Estimate
  ↓
Visual Direction
  ↓
Figma MASTER × 3 sizes
  ↓
Asset Pipeline
  ↓
Frontend Implementation
  ↓
Motion + Interaction
  ↓
API / Product Integration
  ↓
QA + Performance + Accessibility
  ↓
Deployment
  ↓
Evidence / Portfolio
  ↓
Support / Reuse / Next Sale
```

The objective is to make premium creative frontend work sellable without rebuilding the process from zero for every client.

---

## 1. What Makar sells

Makar sells outcomes, not hours.

### Package A — Cinematic Landing

For campaigns, studios, premium products and launches.

Includes:
- discovery brief;
- visual direction;
- one MASTER;
- desktop/tablet/phone;
- custom icon treatment;
- hero scene;
- restrained motion;
- responsive implementation;
- performance pass;
- deployment package;
- before/after visual evidence.

### Package B — Interactive Product Frontend

For SaaS, AI tools, dashboards and creative workspaces.

Includes everything in Package A plus:
- component system;
- application shell;
- real forms/states;
- API integration;
- information hierarchy;
- workspace/panel logic where needed;
- loading/empty/error states;
- visual regression tests.

### Package C — Cinematic AI Studio / Character Product

For products like BOOK-CRAFT / ALina.

Includes everything in Package B plus:
- character system;
- environment layers;
- seasonal/campaign themes;
- motion grammar;
- HUD/floating widgets;
- image/voice/avatar integration;
- asset registry;
- visual QA pipeline;
- reusable theme engine.

These are product packages, not fixed prices. The estimate is derived from scope and risk.

## 2. Commercial estimation model

Never quote a project only by page count.

Estimate dimensions:

- number of unique compositions;
- number of responsive states;
- component count;
- custom icon count;
- hero/character asset complexity;
- motion tier;
- 3D/WebGL tier;
- API integrations;
- content/data states;
- accessibility requirements;
- visual QA depth;
- browser/device matrix;
- deployment complexity;
- deadline compression;
- third-party license costs;
- post-launch support.

A practical internal formula:

```text
Commercial effort =
  base composition
+ responsive recomposition
+ assets
+ component engineering
+ motion
+ integrations
+ QA
+ deployment
+ risk reserve
```

Makar must expose assumptions and exclusions before work begins.

---

## 3. Reusable IP vs client-specific layer

To make money repeatedly, Makar must separate reusable factory IP from project-specific work.

### Reusable factory layer

- tokens engine;
- UI primitives;
- responsive grammar;
- motion primitives;
- scene/asset contracts;
- icon normalization tooling;
- visual QA;
- performance budgets;
- component scaffolds;
- deployment patterns;
- project templates.

### Client/project overlay

- brand;
- copy;
- hero character;
- backgrounds;
- business logic;
- API credentials;
- campaign assets;
- client-specific integrations.

### Rule

**Never fork the whole factory for one client. Add an overlay.**

## 4. Sales-proof architecture

Every commercial project should automatically generate evidence.

Required evidence package:

- approved visual reference / MASTER;
- desktop screenshot;
- tablet screenshot;
- phone screenshot;
- interaction recording when useful;
- Lighthouse/Web Vitals snapshot where applicable;
- visual regression status;
- accessibility status;
- commit/release identifier;
- list of real integrations;
- list of mock/demo data;
- known deviations;
- client-approved final state.

This package serves:
1. acceptance;
2. portfolio;
3. future sales;
4. reusable lessons;
5. skill evidence for Makar.

## 7. Scope gate before production

Makar must not start a commercial build from a vague request.

The scope gate requires:

- deliverables;
- three canonical breakpoints;
- motion tier;
- integration list;
- asset ownership;
- number of review rounds;
- acceptance criteria;
- deployment target;
- explicit exclusions.

Any change after the gate becomes a tracked scope change.

## 9. Asset and rights discipline

Commercial beauty requires legal and technical provenance.

For each asset record:

- source;
- creator/generator;
- model/tool;
- license/permission;
- client-supplied flag;
- modification history;
- stable asset ID;
- final optimized derivatives.

Do not ship unknown-license fonts, stock images, icon packs or media into a commercial project.

---

## 10. Production economics

The factory becomes profitable by reducing repeated work.

Track per project:

- total implementation time;
- time spent on reusable vs client-specific work;
- visual QA iterations;
- rework percentage;
- asset-generation iterations;
- reusable components created;
- components reused;
- performance defects;
- post-release defects.

The target is not "work faster at any cost".

The target is:

**higher visual quality + less repeated work + predictable delivery.**

## 12. Three tiers of visual ambition

### Core
- real UI;
- strong composition;
- responsive;
- restrained motion;
- lowest runtime risk.

### Premium
- cinematic lighting;
- custom assets;
- motion choreography;
- character/hero layering;
- advanced responsive composition.

### Signature
- rich scene system;
- advanced character presence;
- adaptive themes;
- Canvas/WebGL when justified;
- complex motion;
- highest QA and performance evidence.

The tier must be agreed before estimate and implementation.

---

## 14. Commercial Definition of Done

A paid creative frontend project is done only when:

- scope is traceable;
- MASTER is approved;
- desktop/tablet/phone are delivered;
- real UI is separated from art layers;
- assets have provenance;
- critical states work;
- integrations are labeled real/demo;
- performance budget is checked;
- reduced-motion fallback exists;
- accessibility basics pass;
- deployment/release is reproducible;
- acceptance evidence is captured;
- reusable lessons are promoted back into the factory.
