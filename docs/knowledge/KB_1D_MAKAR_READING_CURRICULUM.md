# KB-1D — Makar Professional Reading Curriculum

## Purpose

This curriculum turns books into **operational knowledge for Makar**, not a passive PDF archive.

Every source must move through the same learning pipeline:

```text
Source
  ↓
Catalog + metadata
  ↓
Chapter map
  ↓
Principles / patterns / anti-patterns
  ↓
Recipes / checklists / tests
  ↓
Makar KB items
  ↓
Exercise
  ↓
Application in BOOK-CRAFT / ALINA
  ↓
Evidence
  ↓
Skill level update
```

Reading alone never increases Makar's skill level. Skill grows only after application and evidence.

# Knowledge extraction contract

For every book, ALINA should create:

```json
{
  "source_id": "book:<slug>",
  "metadata": {},
  "chapter_map": [],
  "principles": [],
  "patterns": [],
  "anti_patterns": [],
  "recipes": [],
  "checklists": [],
  "tests": [],
  "examples": [],
  "candidate_knowledge_items": [],
  "exercises": [],
  "projects_used_in": [],
  "evidence": []
}
```

Do not promote every extracted statement to Makar KB.

Promotion requires:
- relevance;
- clear source;
- no contradiction with higher-priority constraints;
- practical usefulness;
- successful application or explicit validation when appropriate.

# BOOK-CRAFT learning lab

BOOK-CRAFT becomes Makar's first visual-commercial training ground.

Each Wave 1 book must produce at least one concrete application in BOOK-CRAFT.

Examples:
- Atomic Design → component decomposition;
- Design Systems → Figma/token library;
- Refactoring UI → spacing/hierarchy cleanup;
- Designing for Emotion → heroine/personality contract;
- Designing Interface Animation → motion grammar;
- The Visual Story → composition/attention map;
- Color and Light → lighting palette;
- Designing for Performance → cinematic performance budget;
- Articulating Design Decisions → review template;
- Pricing Creativity → estimate model.

---

# Definition of learned

A book or chapter is not marked learned because it was summarized.

A knowledge unit is learned only when:

1. extracted;
2. understood;
3. mapped to a task;
4. applied;
5. tested/reviewed;
6. evidence recorded;
7. lesson retained or rejected.

---

# Core principle

**Books feed the factory only when knowledge becomes an executable pattern.**
