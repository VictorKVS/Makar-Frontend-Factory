# Mastery and Evidence

## Evidence hierarchy

Different evidence proves different things.

Examples:

- reading → exposure;
- quiz/explanation → understanding;
- exercise/lab → guided application;
- independent project/production task → independent application;
- reusable library/pattern → pattern creation;
- review and improvement of another implementation → K6 evidence.

The hierarchy is not a fixed numeric truth. Evidence stores both **kind** and **capability demonstrated**.

## Hard rules

1. Unverified evidence does not promote mastery.
2. Reading alone cannot prove applied skill.
3. K4+ requires independent evidence.
4. Evidence can create a promotion proposal, not an automatic promotion.
5. Critical graduate requirements may block graduation when evidence is missing even if a mastery record says K4.
6. Stale evidence can later be down-weighted through recency policy.

## Why

This preserves a distinction between:

```text
ALINA delivered knowledge
        ≠
student read knowledge
        ≠
student understood knowledge
        ≠
student can perform independently
```
