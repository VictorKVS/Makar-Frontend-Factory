# Next step — Makar curriculum decomposition

The metamodel comes first. The next phase is to expand the Makar graduate standard, one competency at a time.

For every competency:

```text
Competency
  ↓ consists-of
Skills
  ↓ require
Knowledge / Tools / Patterns
  ↓ taught-by
Lessons
  ↓ practiced-by
Exercises / Labs / Projects
  ↓ verified-by
Assessments
  ↓ evidenced-by
Evidence
```

## First competency to expand

`competency.design-systems`

Reason: M0.1 and M0.2 already produced strong real evidence, so this domain is ideal for validating diagnostic mapping.

## Required output for the first expansion

- complete skill list;
- prerequisite knowledge nodes;
- tools/patterns/anti-patterns;
- labs;
- assessment gates;
- mapping of existing PR/test evidence;
- initial mastery proposal for Makar;
- adaptive path showing what is skipped, shortened or still required.

Only after this loop works end-to-end should the remaining graduate competencies be expanded.
