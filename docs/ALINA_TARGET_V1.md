# ALINA Target V1

The current cinematic ALINA concept is the visual north star for Project 001, not a pixel-perfect mandate.

## Target layers

### Workspace
- left navigation;
- central task stage;
- right context/activity region;
- top status;
- bottom command input;
- optional floating panels.

### Information streams
- active task;
- context;
- metrics;
- event feed;
- agent activity;
- alerts;
- background processing.

### Visualization
- knowledge graph;
- metrics;
- timelines;
- maps/globe;
- analytical panels.

### Avatar
- ALINA identity;
- holographic/cinematic presentation;
- compact presentation;
- voice-only mode;
- state-driven expression and gesture.

### Ambient / cinematic
- depth;
- parallax;
- glass;
- controlled glow;
- particles;
- 3D scene;
- environmental light.

## First functional success criteria

- recognizably ALINA/FATHER;
- responsive on laptop, desktop and ultrawide;
- useful without 3D;
- real component boundaries;
- visibly marked mock data during early development;
- path to real data without rewriting the UI.
