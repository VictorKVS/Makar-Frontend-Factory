# M1.4 — Context

The M1.3 Data Gateway is accepted and remains responsible for transport, provenance and runtime state.

M1.4 adds graph semantics above that transport boundary.

Rules:
- graph model is renderer-independent;
- workspace state is presentation state only;
- stable IDs are mandatory;
- accessible meaning must survive without visual edges;
- contradiction is semantic, not color-only;
- ProductShell may choose a renderer but cannot redefine graph meaning;
- DEMO provenance remains visible.
