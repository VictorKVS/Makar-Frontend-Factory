# M0.3 — Acceptance Contract

Accepted when:

- `packages/workspace-engine` contains typed serializable contracts;
- core transitions exist for dock, float, collapse, focus, restore and responsive mode;
- transitions are deterministic and unit-tested;
- workspace state survives serialize/deserialize round-trip;
- shared engine imports no ALINA application code;
- ALINA demo renders at least three registered modules from workspace state;
- keyboard focus remains visible;
- laptop / desktop / ultrawide visual evidence is produced;
- M0.3 RESULT records context quality and rework;
- Repository Contract is used as execution input.
