# M1.2 — Context

M1.1 defined seven semantic product planes and a machine-readable shell contract.

M1.2 renders that contract.

## Required behavior

- one primary work context;
- secondary information obeys an attention budget;
- avatar presentation depends on scenario and performance tier;
- product meaning survives Core mode;
- diagnostics remain available but do not dominate the homepage;
- all synthetic content is marked DEMO/MOCK.

## Quality

Use the current repository CI, `quality-budget.json`, shell-contract validator and Playwright suite.
