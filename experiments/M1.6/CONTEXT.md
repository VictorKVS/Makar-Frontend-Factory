# M1.6 — Context

M1.5 is accepted. ALINA has a real avatar render-plan boundary and explicitly reports missing 3D capability.

M1.6 supplies the cinematic renderer capability, but only when initialization succeeds.

Rules:
- do not move ALINA state into WebGL;
- do not make WebGL mandatory;
- use stable scene/asset IDs;
- lifecycle cleanup is mandatory;
- reduced motion disables continuous cinematic animation;
- Core and Enhanced remain valid product modes;
- quality budget is part of acceptance.
