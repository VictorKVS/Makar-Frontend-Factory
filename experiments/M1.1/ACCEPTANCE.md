# M1.1 — Acceptance

M1.1 is accepted when all of the following are true:

- seven ALINA product planes are defined;
- every plane has an owning engine;
- every target visual element is mapped to an existing capability or a named new requirement;
- Research, Coding, Security, Presentation and Focus scenarios each have exactly one primary module;
- each scenario declares secondary/background/alert/agent behavior;
- each scenario declares ALINA avatar presence;
- laptop, desktop, ultrawide and narrow transformations are explicit;
- Core, Enhanced and Cinematic tiers are defined;
- every cinematic-only capability has a lower-tier fallback;
- the machine-readable product-shell contract can be consumed by M1.2;
- decisions expose stable reason tags for future Composition Engine traces.
