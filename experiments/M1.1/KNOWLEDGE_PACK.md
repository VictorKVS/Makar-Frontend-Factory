# M1.1 — Knowledge Pack

ALINA selected a bounded set of six items for Makar.

## 1. Composition engines remain independent

`makar.composition.engines_remain_independent`

Composition chooses and arranges engine outputs; it must not become a god component.

## 2. Stream semantic priority

`makar.stream.semantic_priority`

Arrival time does not determine visual prominence. Primary, secondary, background, alert and agent activity remain semantic classes.

## 3. Avatar renderer independence

`makar.avatar.state.renderer_independence`

ALINA identity, task and attention survive transitions between hologram, portrait, compact and voice-only presentation.

## 4. Workspace state separation

`makar.workspace.state.presentation_separation`

Layout and focus are presentation state. Product/domain payload remains outside the layout model.

## 5. Composition reason trace

`makar.composition.reason_trace`

Automatic layout/presence decisions need inspectable reason tags.

## 6. Visualization intent before renderer

`makar.visualization.intent_before_renderer`

Choose compare/trend/inspect/relate/locate/sequence/monitor intent before selecting graph, chart, map, canvas or 3D representation.

## Intentionally omitted

Additional relevant items were omitted by the attention budget and remain retrievable on demand. This is a deliberate test of smallest-sufficient context.
