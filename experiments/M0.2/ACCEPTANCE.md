# M0.2 — Acceptance Contract

The task is accepted when:

- reusable UI primitives exist in `packages/ui`;
- primitives consume shared semantic tokens;
- a live Visual Token Lab demonstrates the system;
- focus states are visible;
- reduced-motion behavior exists;
- mock/demo content is labeled;
- responsive behavior is checked at laptop, desktop and ultrawide widths;
- tests/typecheck pass;
- screenshots or equivalent visual evidence are attached to the result;
- the result records what context was useful, missing or redundant.
