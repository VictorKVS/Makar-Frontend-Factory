# BOOK-CRAFT — Content Intelligence Map v1

## Product rule

Analytics is embedded in every creative module, not isolated on one analytics page.

## Global navigation addition

Add a product-level entry:

- `Аналитика` → `/analytics`

Optional compact entry in header once layout space is validated.

## Module overlays

Every module exposes a compact analytics strip:

- current performance;
- trend direction;
- confidence;
- recommended next action.

## Shared widgets

- `TrendRadar`
- `HitPatternCard`
- `OpportunityCard`
- `ForecastBadge`
- `EvidenceDrawer`
- `ExperimentPanel`
- `ProductionEfficiencyCard`

## Home page / hero integration

Do not overload the hero.
Use one compact business/intelligence HUD slot:

```text
TREND RADAR
↑ Rising: fantasy worlds
↑ Rising: short audio stories
→ Stable: character-driven series
Confidence: 0.74
Horizon: 14 days
```

This replaces random decorative analytics with a real product capability.
